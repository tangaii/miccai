# External checkpoint bundle

Trained assets are intentionally not distributed with this initial release.
Place a user-trained or otherwise authorized bundle in a directory passed with
`--checkpoint-dir`.  The runtime expects these descriptive filenames:

| File | Consumer | Producer/status |
| --- | --- | --- |
| `classification_route_manifest.json` | classification routing | external/data-derived curation; no public producer |
| `classification_heads.pt` | semantic classification branch | `train.py --component classification-head` |
| `multilabel_template_map.json` | MLC prompt metadata | external/data-derived preparation; no public producer |
| `multilabel_candidate_library.json` | structured MLC candidates | external/data-derived preparation; no public producer |
| `multilabel_candidate_selector.cbm` | candidate selector | `train.py --component multilabel-selector-ranker` |
| `multilabel_candidate_ranker.cbm` | candidate ranker | `train.py --component multilabel-selector-ranker` |
| `multilabel_probability_models.joblib` | atom/cardinality priors | `train.py --component multilabel-probability-models` |
| `multilabel_residual_head.pt` | token-conditioned residual head | `train.py --component multilabel-residual-head` |
| `regression_visual_model.joblib` | visual regression estimator | `train.py --component regression-visual-estimator` |
| `regression_reference.joblib` | source feature/reference table | `train.py --component regression-reference` |
| `regression_residuals.npz` | cross-fitted residual correction | `train.py --component regression-residuals` |
| `regression_quantile_head.pt` | spatial quantile head | `train.py --component regression-quantile-head` |

The base model and two PEFT adapters are also external inputs.  The public
repository provides a generic adapter-training API, but no root CLI producer
for the final adapter directories:

```text
--base BASE_MODEL_DIR
--adapter OFFICIAL_ADAPTER_DIR
--reg-adapter REGRESSION_ADAPTER_DIR
```

The base model must identify as `google/medgemma-1.5-4b-it`; each adapter must
be a single PEFT LoRA adapter trained for that same base.  The runtime loads
the adapters sequentially and never combines adapter weights.  It audits the
source/target visual-tower orientation and rejects missing or unexpected
adapter tensors rather than silently continuing.

The route manifest and template/library files must use the schemas consumed by
the public runtime.  If they originate from an external competition package,
the conversion to these descriptive filenames and schemas is an external,
data-derived preparation step and is not claimed to be generated by `train.py`.

Do not commit trained weights, fitted estimators, private retrieval tables, or
input-specific feature caches.  Keep them in an external directory ignored by
Git.
